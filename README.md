# Анализ каталога фильмов
 
Домашнее задание 1 по дисциплине Программирование на Python.
Студент и группа: Хафизов А.Ш. m26-555.
 
## Требования
 
- Python 3.12, выбранный через uv
- uv версии не ниже 0.5
- Ruff установлен как зависимость для разработки
 
## Запуск
 
Из папки проекта выполните:
 
    uv sync
    uv run catalog_analysis.py
 
## Проверка оформления
 
    uv run ruff check .
 
## Содержание решения
 
В catalog_analysis.py реализованы все 9 этапов и 22 задачи.
Используется стандартный модуль math и встроенные средства Python.
Один вызов build_report(movies) печатает основной отчет и дополнительные
результаты анализа. Исходный каталог сохранен без изменения названий.
